# Grand Palais Art Gallery

A modern, responsive multi-page art gallery website with a professional museum-style design.

## Features

- **Modern & Minimalist Aesthetic:** Designed to mirror the elegant feel of top art museums.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewing.
- **10 Featured Artists:** Deep profiles on Picasso, Van Gogh, Da Vinci, Monet, Rembrandt, Michelangelo, Dalí, Kahlo, Vermeer, and Munch.
- **Dynamic Artist Detail Page:** Artist biographies and achievements populated via JS.
- **Gallery & Filter System:** Filterable artwork grid with a functional lightbox modal.
- **Dark/Light Mode:** Persistent theme toggle with smooth transitions.
- **Modern Tech Stack:** Built with Vite, Bootstrap 5, and SCSS.

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## Folder Structure

- `src/`: Contains all HTML pages and source assets.
  - `assets/js/`: JavaScript logic and data storage (`data.js`).
  - `assets/scss/`: Styling with SCSS variables for theming.
- `vite.config.js`: Configuration for the multi-page build.
